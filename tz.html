ĐỊNH DẠNG VĂN BẢN VỚI CSS

CSS là gì?

CSS là ngôn ngữ được sử dụng để định dạng và thiết kế giao diện cho các trang web. CSS giúp thay đổi màu sắc, kích thước chữ, căn chỉnh văn bản và tạo bố cục đẹp mắt cho trang web.

Với CSS, chúng ta có thể dễ dàng kiểm soát cách hiển thị của các thành phần HTML trên trang web và tạo ra những giao diện trực quan, thân thiện với người sử dụng.

Đây là đoạn văn bản được căn giữa.
